How ARCT works

  1. A theorem has one statement and topic tags.
  2. Contributors can add multiple insights explaining intuition, tricks, or applications.
  3. Contributors can add multiple proofs, including different methods.
  4. LaTeX is rendered for readable mathematics. Contributions are public, so do not include private information.
